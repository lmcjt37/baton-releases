# Examples

Small apps to try Baton on before pointing it at your own project. Each has a `baton.config.ts` and tests that assert a visible marker: Maestro flows in `.maestro/`, or Detox tests in `e2e/`.

| Example | |
|---|---|
| [bare-rn](bare-rn) | Bare React Native 0.87, iOS and Android |
| [bare-rn-detox](bare-rn-detox) | The same app with Detox tests instead of Maestro flows, iOS and Android |
| [expo-dev-client](expo-dev-client) | Expo SDK 57 with `expo-dev-client`, iOS and Android (native folders generated by `expo prebuild`) |

```sh
cd examples/bare-rn
npm install
baton perform smoke
```

**See the isolation for yourself:** copy an example, change `MARKER` in the copy's `App.tsx` and `EXPECTED_MARKER` in its `baton.config.ts`, then run `baton perform smoke` in both folders at once. Each run passes only if its own simulators show its own code.

**See failures, flaky flows and Encore:** in `bare-rn`, run `baton perform demo`, then `baton encore <id>`. See its [README](bare-rn/README.md#failures-retries-and-encore), or [bare-rn-detox's](bare-rn-detox/README.md#failures-retries-and-encore) for Detox.
