Why Baton

  • A Metro per worktreeEvery worktree gets its own port, so no simulator loads another branch's code.
  • Its own devicesDedicated simulators and emulators, checked to load the right bundle before any flow runs.
  • Queued, not failedRuns wait for free devices instead of fighting over them.
  • Built onceApp builds are cached by native fingerprint; JS-only branches never rebuild.
  • Agent-readyOne MCP call runs the flows and returns results and screenshots.
  • Watch it liveA menu bar dashboard with progress, screenshots, logs and a live device grid.

Install

curl -fsSL https://lmcjt37.github.io/baton-releases/install.sh | sh

Downloads the latest release, checks its checksum and signature, installs Baton to Applications and puts the baton command on your PATH. Nothing else to do.

brew install --cask lmcjt37/tap/baton

Installs the app and puts the baton command on your PATH. Then open Baton from Applications once: macOS asks before running an app downloaded from the internet, and baton waits for that.

  1. Download the DMG with the button above.
  2. Open it, accept the licence, and drag Baton to Applications.
  3. Open Baton and click Open if macOS asks. It lives in the menu bar, not the Dock.
  4. From the menu bar icon, choose Install 'baton' Command… to put baton on your PATH.

Whichever you choose, Baton updates itself, and only when no test run is in progress.

Updating by hand

If Baton hasn't updated itself, or you've turned automatic updates off in Settings, update it in any of these ways:

  1. From the menu bar: click the Baton icon and choose Check for Updates… (Baton 1.3.0 and later). It downloads the latest version, installs it and restarts Baton, waiting for any test run to finish first.
  2. With Homebrew:
    brew upgrade --cask --greedy baton
  3. With the install script, which quits Baton and replaces it with the latest release:
    curl -fsSL https://lmcjt37.github.io/baton-releases/install.sh | sh -s -- --force
  4. By hand: download the DMG with the button above, quit Baton, then drag Baton to Applications and replace the old copy.

To remove it, run brew uninstall --zap --cask baton, or see uninstalling and troubleshooting.

Get started

From your React Native project:

baton init # detect your project, write baton.config.ts baton perform # run your Maestro flows or Detox tests baton ui # open the dashboard

Let your AI agents run flows too:

claude mcp add --scope user baton -- baton mcp

Requirements

macOS with Xcode and an iOS simulator runtime · Maestro 2.11+ and Java, or Detox 20 in your project (plus applesimutils for iOS) · a bare React Native or Expo dev-client app · for Android, the Android SDK with an arm64 system image.
